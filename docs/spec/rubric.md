# 리뷰 루브릭 (멈춤 기준)

모든 역할 리뷰어가 아래 3가지 모두 PASS를 줄 때 루프를 멈춘다.

- C1 완결성: 내 담당 영역에 남은 Blocker/Major 허점이 없다.
- C2 AI 구현 가능성: AI 코딩 에이전트(Claude Code)가 이 기획서만 보고 MVP를 구현할 때, 문서에 없는 제품 결정을 스스로 내려야 하는 지점이 없다. 모든 기능에 입력/출력, 데이터 구조, 수용 기준(acceptance criteria), 측정 가능한 품질 기준치가 있다.
- C3 대기업 통과: 국내 대형 IT 기업(네이버·카카오·토스 수준)의 기획/디자인/기술 리뷰 게이트를 통과할 수준이다(문제 정의, 타깃, 성공 지표, 범위, 리스크, 법무, 운영 포함).

심각도
- Blocker: 이대로면 구현 불가 또는 리뷰 탈락
- Major: 구현은 되지만 결과 품질/리뷰 통과에 큰 영향
- Minor: 개선하면 좋음 (루프 멈춤 판단에는 영향 없음)

맥락: 1인 풀스택 개발자의 개인 프로젝트이지만, 기준은 대기업 수준. MVP 범위와 이후 단계를 구분해서 현실적인 보완을 제안할 것. 과잉 요구(1인이 감당 못할 조직·프로세스)는 "MVP에서는 X로 대체" 식으로 제안.
