# v2 장 작성 공통 지침

목표: 기획서 v2는 (1) AI 코딩 에이전트(Claude Code)가 이 문서만 보고 MVP를 구현할 때 스스로 제품 결정을 내릴 필요가 없고, (2) 국내 대형 IT 기업의 기획·디자인·기술·법무 리뷰 게이트를 통과할 수준이어야 한다.

입력:
- /home/claude/review/spec_v1.md (v1 기획서)
- /home/claude/review/decisions.md (결정 레지스터 — 반드시 준수, 충돌 금지)
- /home/claude/review/rubric.md (루브릭)
- /home/claude/review/r1_*.md (1라운드 역할별 리뷰. 각 항목에 보완안이 있음)

작성 규칙:
- 한국어, 명세서 문체("~한다"). 서론·요약 반복 금지. 표·스키마·수식·의사코드·수치를 적극 사용.
- 담당 리뷰 항목의 Blocker/Major 보완안을 빠짐없이 반영하되, 결정 레지스터와 다르면 레지스터를 따른다. 반영한 항목 ID를 장 끝 "반영 추적" 표에 남긴다(ID → 반영 절).
- 모든 기능에: 입력/출력, 데이터 구조, 수용 기준(AC-<장번호>-<번호>, Given/When/Then 또는 측정 가능한 문장), 수치 기준.
- MVP(P0)와 Phase 2/3을 명확히 표시. MVP에서 제외하는 것은 "MVP 제외"라고 명시.
- 모호한 표현("적절히", "좋은", "어울리는") 금지 — 수치나 규칙으로.
- 다른 장의 영역은 직접 정의하지 말고 "→ 0X장 참조"로 연결. 다른 장에 필요한 값을 정해야 하면 "추가 결정" 절에 D-<장번호><번호> 형식으로 제안.
- 법률·라이선스 사실은 "출시 전 원문 확인" 조건을 붙인다.
- 파일 하나로 저장. 마크다운 제목은 "# 0X. 장 제목"으로 시작, 하위는 ##, ###.
- 완료 후 반환: 파일 경로, 크기, 추가 결정 목록, 다른 장과 맞춰야 할 인터페이스(이름·스키마) 목록만 간단히.

장 목록(참고 — 교차 참조용):
00 개요·전략(문제, 타깃, 가치, 경쟁, 지표, 범위·로드맵, 리스크) / 01 사용자 여정·화면 명세 / 02 진단 시스템 / 03 디자인 시스템·택소노미 / 04 생성 파이프라인·품질 게이트 / 05 레퍼런스·트렌드 데이터 / 06 기술 아키텍처 / 07 품질 보증·출시 기준 / 08 법무·개인정보·보안 정책 / 09 구현 계획(레포·마일스톤·자율 구현 운영 규칙)
