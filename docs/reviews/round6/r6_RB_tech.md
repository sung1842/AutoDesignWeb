## 2. 새 항목

Blocker 0 · Major 0.

### Minor(기록만, 반영하지 않음)
- m1(06 AC-06-61 ④ 둘째 문장, 09 9.6.2 지연): "같은 설정에서 후보 0 실패 주입 시" 문장이 어떤 시나리오(예: `server_error@0`)로 실패를 주입하는지 정하지 않는다. Mock 오류 응답에도 `MOCK_LLM_LATENCY_MS`가 적용되는지도 정하지 않는다. 오류 응답이 4000ms 뒤에 오면 실패 시각이 t1(t0 + 3s)보다 늦다. 그러면 V-01 규칙상 cached로 추정되어 기대값과 어긋난다. 오류 응답은 지연 없이 즉시 온다고 적으면 된다. 같은 경로에서 `budget_skipped` 기대값(후보 0 재시도 예약 포함 여부)도 적혀 있지 않다.
- m2(07 7.12.1 tuning-log 스키마): `gateRun` 항목의 `cached` 값이 정해지지 않았다. 8c는 dev 항목만 세므로 판정에는 영향이 없다. `gateRun` 항목은 `cached=false`로 고정한다고 적으면 바이트 동일성(AC-02-36 ①⑦)이 더 확실해진다.
- m3(06 6.9.4 ⑥ `cost:model`): 괄호 "mock 단가 0.23676"은 예시값이다. 본문은 `models.yaml` 단가로 다시 계산한다. 그러니 "mock 단가에서 0.23676"으로 적어야 리터럴 비교로 오해하지 않는다.
